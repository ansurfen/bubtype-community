# BubType Community

Open-source edition of [BubType](https://bubtype.com) — caption typing + word lookup.

**License:** [Apache License 2.0](./LICENSE)

This tree is **extracted** from the private commercial repo. It does **not** include:

- Pro skins / particle sprites
- Pro key-sound packs
- License / account unlock
- PDF / example export

```bash
npm install
npm run dev      # community mode
npm run build
```

Commercial Pro builds live in a separate private repository.
